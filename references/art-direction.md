# 风格、角色与镜头规范

## 宫崎骏／吉卜力式治愈动画预设

这是本项目的默认风格预设，可以按使用者偏好替换。作品角色、故事和构图仍根据用户想法原创，不把结果称为宫崎骏或吉卜力官方作品。

基础提示词：

> 宫崎骏／吉卜力式二维手绘动画电影风格，原创人物与生活场景。干净、纤细而有变化的动画轮廓线，人物使用简洁的赛璐璐色块和柔和阴影；背景是精细绘制的传统动画背景，保留手绘笔触但轮廓清晰。鲜活而有层次的草绿、深绿和青绿，明亮的天空色，奶油白与蜂蜜木色平衡画面，粉色与黄色花朵少量点缀。自然光通透，暗部保留颜色。前景叶片与花草、中景人物和生活道具、远景田野形成纵深。真实可感的食物、蒸汽、风、雨滴和织物微动作，平静、温柔、有生活气息。

按场景增补而不是把所有元素都塞进每镜。雨天仍保留叶片和室内物体的色彩；晴天则强调透光叶片、清晰云层与轻柔阴影。避免泛黄怀旧滤镜、整幅灰褐色、苍白洗淡、模糊水彩边缘、塑料 3D、矢量扁平插画和夸张的萌系头身比。

英文提示可用明确风格词：`Hayao Miyazaki / Studio Ghibli-inspired hand-drawn 2D animated film aesthetic`，随后保留同样具体的视觉描述。

选择中国农村题材时，先按 [年代与地域设定](rural-china-2000s.md) 固定建筑、植被、衣着和器物，再应用上述线条、色彩与表演方向。不能用统一的欧式小屋、日式室内或全年盛放的花园替代具体生活环境。

## 风格样张先于视频

1. 选一个同时有角色、生活道具、植物和光线关系的代表性镜头制作样张。
2. 看图比较：绿色是否鲜活而有层次？人物轮廓与背景是否属于同一动画世界？有无全局棕黄/灰蒙滤镜？主体是否清楚？环境细节是否丰富但有主次？
3. 将通过的图设为项目风格锚点；之后重复使用同一文件，不每镜重新口述一遍就当作约束。
4. 如有用户原始参考视频，提取少量关键帧用于分析、对照色彩与构图；确认工具实际接受该参考才声明条件输入成功。参考素材不自动成为公开交付内容。

## 视觉设定文件应包含

- `style_version`、已检查的风格锚点文件和简短判定。
- 角色 ID：年龄段、发型/发色、头身比例、眼鼻轮廓、服装颜色和配件。正面、侧面、半身参考应互相一致。
- 场景 ID：窗门相对位置、桌子、炉灶、花园方向、主要材质和时间天气。可制作场景总览图。
- 道具 ID：例如陶碗有无耳、杯形、汤色、面包数量。涉及连续镜头时具体写出。
- 音频方向：环境、音乐、旁白语言/声音，以及哪些镜头有明确拟音。

## 同一部片的视觉基准

在`visual_bible`（视觉设定）记录已通过的风格锚点文件及版本、角色/场景/道具参考、轮廓和阴影做法、主色关系、材质完成度与光线进程。选择的基准应贴合用户参考；后续各镜重复使用同一批实际素材，而非每次重新生成一套参考。

角色记录年龄、头身比例、身高、发型、五官、衣服和配件；动物记录体型、毛色分区与花纹。场景记录平面关系、地平线/消失方向、门窗、台面和座椅尺寸，以及人物脚底和地面的接触。比较同一深度的投影比例，近景人物不能直接与远处门洞按像素比高；空间复杂时先做布局或尺度示意，再绘制完成稿，不把示意图直接当最终首帧。

逐镜同时与风格锚点、前后镜比对：线条和色块是否一致，人物年龄与体型有无漂移，服装和器物是否变化，背景细节是否属于同一画风，房间格局和光向是否连续。锚点不会保证模型必然服从，需实际看产物。发现漂移先修本镜，不为迁就坏镜头重定义整片基准。

镜头首帧还应服从动作开始状态：杯子未放下就不能已在桌上，书包未取下不能已铺在地面；已完成的动作也不在下一镜重演。下一镜可从上一镜实际可用末帧续接；换景别或机位时，用同一版身份与场景参考重画，并保留当时的物品数量、握持和位置关系。

## 提示词分层

**参考图提示词** = 风格基准 + 角色/场景固定信息 + 本张参考的用途和构图。

**镜头图提示词** = 风格锚点/角色参考/场景参考的实际输入 + 景别 + 主体位置 + 动作开始状态 + 重要道具 + 光线。动起来前，静态画面先正确。

**视频提示词** = 单镜头声明 + 从首帧开始的动作阶段 + 可见位移与速度变化 + 跟随运动 + 一个明确运镜 + 结果/切点 + 镜头声音 + 必要画风/身份约束。身份由真实参考输入约束，提示词作为补充。详见 [动作与声音](motion-and-sound.md)。

例如：

> 单个连续 6 秒镜头，保留输入图片的宫崎骏／吉卜力式二维手绘画风、人物和厨房布局。固定侧面中景，正常生活速度。0–1 秒女孩右手将木勺伸入浓汤；1–4 秒沿锅内壁顺时针搅拌一圈，手腕转动带动前臂，汤面在勺后形成旋涡；4–6 秒将勺提离汤面，少量汤汁滴回锅中，液面余波逐渐减弱。蒸汽持续上升，袖口随手臂动作稍滞后摆动。锅和桌子保持刚性，手与勺接触关系连续；不自动切镜。只生成煮汤与木勺拟音，不生成对白或片段配乐；整片音乐由后期独立铺设。

时间段是动作编排目标，生成后仍须核对执行情况。不要把“物体形状稳定”扩大成角色全身不能动；留给姿态、表情、衣物和重心自然变化的空间。

同一 seed 或同一文字不会锁住身份。首帧已准确表现风格时，不用冗长文字重新描述另一套构图。

## 丰满的生活过程

默认90–120秒的解压片，用相互关联的准备、执行、互动和享受展开。例如“傍晚泡茶”可包含收拾阅读角、备茶、猫醒来、为猫铺软布、一起安顿下来，结尾的茶、书和位置回应前面的准备。故事可以轻，过程与情绪仍要完整；不强加冲突或旁白解释，也不只罗列蒸汽、花草和落日。

系列共享审定的视觉基准，每集改变具体生活过程和感受。剧本与系列规划见 [series-production.md](series-production.md)。

## 场景约束落到镜头

每处空间建立一个 `layout_version`：世界坐标的门窗墙面、固定水龙头/水槽、炉台、桌椅相对关系与尺度、光源方向。相机换位只改变投影，不改变世界方位；不能把“画面左边”当房间永恒的“西侧”。斜视图应标记镜头方向/轴线，保持桌面和器物同一透视。

首帧先核查操作空间：杯与壶是否能从水龙头下方通过、壶盖是否已取下、台面是否留出比托盘底面更大的空位、手能否碰到开关。没有落点的构图先修图，不让视频提示词凭空挪家具或把书变没。空间、容量、尺寸必须来自已通过参考；数值仅作为规划依据，实际生成后再看图核对。

跨镜用道具状态表维护数量、位置、朝向、液位、开合/开关；参考图与实拍/生成的剪辑末态矛盾时，重画相应首帧或修改后镜。详见 [镜头契约](shot-contracts.md)。
