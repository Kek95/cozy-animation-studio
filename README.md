# Cozy Animation Studio · 治愈动画工作室

**给 Codex 一个生活想法，让它完成从剧本到成片的制作。** 默认制作90–120秒的原创二维手绘治愈动画：有多种日常活动、自然动作、统一人物与空间、连续背景音乐和环境声。也支持30秒测试、系列和已有镜头的局部修改。

```text
想法 → 生活段落 / 剧本 / 主题 → 分镜与声音表
     → 风格、角色、场景参考 → 实际引用参考生成镜头图
     → 代表性动作试片 → 逐镜视频 → 筛选 / 局部重做
     → 正常速度剪辑 → 配乐 / 环境声 / 必要对白
     → 真实切点检查 / 播放听检 / 技术检测 → MP4与过程归档
```

核心不绑定生成平台。图片、视频、音乐和语音可分别连接直接API、现有工具/SDK、用户素材或可选ComfyUI。默认美术为宫崎骏／吉卜力启发的手绘风格；原创角色、故事和场景，与创作者、工作室和模型供应商无隶属关系。

## 安装与第一次使用

需要 Codex、Python3.10+、`ffmpeg`和`ffprobe`，以及你有权限使用的图片、视频与音乐服务。Skill不附带模型、API额度或账号。只有选择ComfyUI路线才需要安装ComfyUI及对应节点。

下载本仓库或克隆后运行：

```bash
git clone https://github.com/Kek95/cozy-animation-studio.git
cd cozy-animation-studio
python3 scripts/install.py
```

已安装旧版时使用 `python3 scripts/install.py --replace`，会先备份旧安装再替换。默认安装到 `~/.codex/skills/cozy-animation-studio`，尊重 `CODEX_HOME`，也支持 `--dest` 和 `--dry-run`。在新对话中调用以确保加载新版。

安装后可以只说：

> 使用 $cozy-animation-studio，做一部“雨后小镇里普通而舒服的一天”。主角去街角买东西，回家做手作、喝饮料，最后在窗边休息。请直接制作约105秒成片，加背景音乐和环境音，过程文件按生成时间归档。沿用我已连接的生成服务。

如果服务还没配置，补充平台名和文档链接即可。Codex会先整理创作与接入，只询问确实缺少的接入信息；密钥使用环境变量或服务原生登录，不发到聊天和Git里。已有制作授权和可用服务时，代理自动推进各阶段，不要求你逐镜操作。生成会消耗你所用服务的额度，先遵守你设定的预算与模型限制。

其他用法：

> 做30秒测试，生图全部使用本机ComfyUI；视频限定Seedance 2.0 Fast或Mini，禁止2.5。先验证倒水动作再扩展；正常速度、切镜利落，背景音乐跨镜连续。

> 继续已有项目，只修S08壶嘴没对准杯口的问题，保留其他通过的镜头。

> 先规划海边小镇系列，每集90–120秒，暂不生成。

## 这套Skill制作的是什么

默认是**日常生活蒙太奇**：同一生活圈里数种普通活动串成一段有情绪进程的生活，从清新、忙碌到满足、安顿。田边劳作、逛店、归家、享用、手作、阅读、宠物、晚灯都可成为段落；每集按想法换内容，不强制做饭或农村题材。一个单一的小物件通常不足以支撑整集，除非用户明确要求完整呈现某个工序。

| 制作项 | 默认标准 |
|---|---|
| 片长与覆盖 | 90–120秒，目标105秒，约26–36个独立构图；显式30秒约10–12个 |
| 节奏 | 正常1x动作，常用2–4秒有效区间，剪掉等待和尾停，动作/反应切优先 |
| 风格与空间 | 实际传入检查通过的角色/场景参考，固定比例、服装、建筑关系与布局 |
| 动作细节 | 按真实首帧写抓握、承重、净空、接触顺序；高风险动作先试片 |
| 生活气息 | 适当出现其他房屋和做日常事的配角；独处要求优先 |
| 声音 | 跨镜连续配乐、环境底声、同步动作声；必要时才加自然对白 |
| 审核 | 逐镜筛选、有限局部重做、实际成片切口检查、技术检测、真实播放/听检 |
| 交付 | MP4、剧本分镜、项目、素材与实际提示词/脱敏请求、声音来源和检查报告 |

已获认可的原创30秒样片《平常的一天》使用12个独立构图、Mini/Fast混合、独立音乐加环境底声与原生拟音。此次更新把其**多活动叙事、真实参考输入、首帧适配、风险试片、有效区间裁切、最终切口复核**整理为可复用步骤。公开包只含原创规划和通用模板，不包含用户参考视频、抽帧、私有项目、凭据或生成任务ID。

## 自动化如何工作

Codex负责创作、选择工具、看图/审片和修复决策；脚本负责可重复的任务记录、文件/哈希门槛和剪辑。**这不是一个输入提示词就脱离Codex运行的模型或后台服务。** 不需要用户自己逐镜填表；项目与检查记录由执行此Skill的代理维护。

新项目的视频提交检查实际模型允许清单、已接受参考/首帧哈希、条件输入证据和试片记录，防止“口头说引用了”或试片尚未通过就全量生成。跨服务工具/UI也执行同样步骤。检查脚本只能验证记录，图像是否一致、手是否穿模、声音是否自然仍需实际审查；FPS、响度和下载成功不能代替审美验收。

服务、版本、额度和宿主播放/听取能力决定实际可完成的阶段。同样提示词不能保证每次生成相同质量，流程通过试片、筛选和针对性重做接近目标。未完成连续播放或主观听检时，交付明确标为测试渲染并保留待检项，不伪造“全部通过”。

## 开发与验证

```bash
python3 -m pip install -r requirements-dev.txt
python3 scripts/validate_skill.py
python3 -m unittest discover -s tests -v
```

2026-11-09发布前验证：67项自动测试通过；以已有12段原创动画素材运行公开版合成、分层混音、11个真实切口导出与技术检查，得到30秒720p/24fps、720帧、约−18LUFS的测试文件。此验证没有重新调用付费生成；切口图片已实际检查，连续播放/主观听检没有被虚标通过。

运行脚本只用Python标准库，开发校验另需PyYAML，媒体测试另需FFmpeg。CI执行元数据、链接、示例计划、绑定、任务恢复、门槛及本地媒体测试，不调用付费模型。

修改技能、校验或安装不会启动付费生成。项目在独立的时间目录生成，不写入Skill安装目录；每镜默认最多首轮加一次针对性重做，提交结果未知时先查原任务。许可见 [LICENSE](LICENSE)。
